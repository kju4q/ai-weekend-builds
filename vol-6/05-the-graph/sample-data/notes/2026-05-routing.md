# Note, May 2026: my model bill

Invented sample note.

My API bill doubled this month and most of it was summarizing short emails.
Theo Lindqvist's talk "Spend Less on Inference" says most requests do not need the biggest model.
Lindqvist argues for routing each request by task type before looking at prompt length.
This disagrees with what I have been doing, which is always using the biggest model.
I want to build a router that logs what every request costs.
