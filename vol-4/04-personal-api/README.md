# 04. Personal API

**Difficulty**: Medium-Advanced | **Time**: 5-8h

## What it is

A small local server with endpoints for your life. `/today` merges your
calendar, your tasks, and the weather into one response. `/idea` files a thought.
Nothing leaves localhost.

## What you'll learn

What an API is, by building one around your life.

## What you'll need

> Finalized during the build. The list below is the starting assumption, not the
> final one.

- Python 3.10+
- A calendar export and a task file to read from
- A free weather source, no key required
- No model key needed for the core server
