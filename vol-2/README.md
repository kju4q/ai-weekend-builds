# Vol 2: 5 New AI Weekend Builds (May 2026)

5 projects focused on what's actually shippable now: vision-to-code chaining, automation pipelines, structure extraction, prompt chaining, and agent loops. Each one teaches a different shape of AI build.

| # | Project | Difficulty | Time | What you get |
|---|---------|---|---|---|
| 01 | [Screenshot to Code](01-screenshot-to-code) | Easy | 2-4h | Photo of any UI → working React component |
| 02 | [AI Daily Digest](02-ai-daily-digest) | Easy | 3-5h | 5 sources → one morning email of what matters |
| 03 | [Auto-Skill Builder](03-auto-skill-builder) | Medium | 4-6h | Corrections in a chat → installable skill file |
| 04 | [Content Repurposer](04-content-repurposer) | Medium | 4-6h | One post → 5 platform-native versions |
| 05 | [AI Inbox Triage](05-ai-inbox-triage) | Advanced | Full day | Inbox connected → wake to 3 drafts ready |

## Each project covers a different shape of build

- **Vision in (#1)**: vision models reading interfaces, chained with code generation
- **Automation pipeline (#2)**: scrape, summarize, schedule, deliver
- **Structure extraction (#3)**: pull patterns out of unstructured chat history
- **Prompt chaining (#4)**: voice preservation across format transformations
- **Agent loop (#5)**: read, classify, draft, present

By building all 5, you cover most of the patterns you'll use for years.

## Pick one

If you've never built with AI: start with **#1 Screenshot to Code**. Highest "I can't believe this works" energy.

If you want immediate daily value: **#2 AI Daily Digest**. Becomes a real tool you check every morning.

If you want to feel like AI is compounding for you: **#3 Auto-Skill Builder**. Every correction becomes a permanent improvement.

If you write a lot: **#4 Content Repurposer**. Saves hours per week.

If you have an inbox you avoid: **#5 AI Inbox Triage**. Most ambitious, biggest payoff.
